# AI Colony — 自主多智能体协调系统

[![version](https://img.shields.io/badge/version-4.0.0-blue.svg)](main.js)

基于角色的自主多智能体协调系统，在可编程模拟环境中运行。系统通过中央控制循环协调多个专用智能体（Agent），实现资源采集、建造、运输、升级和防御的完整自动化流水线。

---

## 核心特性

- **队列孵化** — 优先级队列替代贪心链，自动预生成替换（提前 50t），多 Spawn 并行
- **Link 网络** — RCL5+ 自动 Source→Controller 远程送能，大幅节省搬运工
- **市场交易** — RCL4+ Terminal 自动买卖能量和多余矿物，赚取 Credits
- **远征采集** — Claimer 续约邻房 + RemoteHauler 跨房间运能，突破单房间经济瓶颈
- **Lab 强化** — RCL6+ 自动从市场购买化合物并强化 Upgrader，升级效率 ×3
- **动态身体部件** — 根据当前能量容量自动缩放 Agent 的部件配置，模式重复法替代固定模板
- **容器经济模型** — RCL2+ 启用定点采集 + 专职运输的流水线作业，大幅提升采集效率
- **CPU 三级降级** — 根据 CPU 预算自动关闭非关键功能（日志/可视化/非必要维修）
- **房间缓存层** — 每个周期仅执行一次环境扫描，结果全周期共享，避免重复查询
- **阶段面板** — 实时显示当前发展阶段（1-5）及各项目标完成进度
- **可视化系统** — 零开销的信息面板、资源流向动画、警报系统，可通过 Flag 切换显示级别

## 发展阶段

| 阶段 | 名称 | 范围 | 核心任务 |
|------|------|------|---------|
| P1 🔰 | 基础·初始积累 | 初始期 | 建立 Agent 生产线，完成基础设施搭建 |
| P2 📦 | 容器·定点经济 | 成长期 | 启用容器缓存 + 定点采集 + 运输流水线 |
| P3 🛠 | 建造·设施完善 | 完善期 | 建造防御设施、仓库，积累能量缓冲 |
| P4 ⚗ | 成长·生产升级 | 爬坡期 | 储能 50K、完善防御、矿物交易系统 |
| P5 🚀 | 扩张·跨房间 | 扩张期 | 远征采集、占领新区、Link 网络 |

## 系统架构

```
每个周期执行一次完整的控制流水线:

  Migration → 内存清理 → 环境缓存 → Agent 统计
  → 房间状态监测 → 防御协调 → Agent 行为调度
  → 孵化队列 → 数据记录 → 可视化渲染
```

详见 [模块架构说明](模块架构说明.md) 了解各个模块的详细运行流程。

## 快速开始

1. 将 `main.js` 部署到运行时环境
2. 系统将自动探测初始位置并启动首个 Agent
3. 观察左上方面板了解系统状态

### 配置调整

所有参数集中在 `main.js` 顶部 `CONFIG` 对象中：

| 参数组 | 说明 |
|--------|------|
| `POPULATION` | 各类 Agent 的数量上下限 |
| `REPAIR` | 建筑维修耐久度阈值 |
| `ENERGY` | 防御设施保留能量阈值 |
| `CPU` | CPU 降级边界值 |
| `LOG_LEVEL` | 控制台输出详细程度 (0-3) |

### 可视化开关

在目标位置放置对应名称的信标即可切换显示模式：

| 信标名 | 效果 |
|--------|------|
| `viz_off` | 关闭全部可视化 |
| `viz_min` | 仅信息面板 + 警报 |
| （无信标） | 默认完整可视化 |
| `viz_debug` | 完整 + 调试标注 |

## Agent 类型

| 角色 | 职责 | 启动阶段 |
|------|------|---------|
| Harvester | 走动式采集，基础能量供应 | P1 |
| StaticHarvester | 定点采集，存入容器 | P2 |
| Hauler | 容器→基地能量运输 | P2 |
| Upgrader | 升级控制核心 | P1 |
| Builder | 按优先级建造建筑 | P1 |
| Repairer | 维修道路和容器 | P1 |
| WallRepairer | 维修城墙和路障 | P3 |
| Claimer | 占领新区（预留） | P5 |
| RemoteHarvester | 远征采集（预留） | P5 |
